cage-doctor（Windows 版）使用说明
================================

一、这是什么
    给 Claude-Cage 做体检的只读工具。窗口里两个页签：
      1) 本机体检：21 项，查系统、Cage 安装、端口、客机 SSH 与登录凭据、时区语言等
      2) 网站检测：真打开 checkcc.org 点一次检测，把总分和 48 项信号明细抓回来
    全部只读，不改配置、不上传数据。

二、怎么用
    1. 解压到 D 盘任意目录，不要放 C 盘
    2. 双击 run-doctor.bat
    3. 先看「本机体检」，再看「网站检测」，点「开始体检」
    4. 需要留底就点「复制报告」，粘贴到记事本

三、前置条件
    · Windows 10 22H2 及以上
    · 已安装 Claude-Cage（D:\Cage\app）
    · 跑网站检测时 Cage 窗口要开着，否则代理/节点那三项会显示「控制器不可用」

四、状态含义
    通过    符合预期
    注意    能用但有隐患
    不合格  硬性问题，不修跑不通
    待办    需要你手动完成（比如登录 Claude、去浏览器点一次检测）

五、脚本被拦截怎么办
    在 PowerShell 里执行一次：
    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

六、调试
    set CAGE_DOCTOR_TAB=web      启动直接进网站页签
    set CAGE_DOCTOR_DEBUG=1      抓取原文写到 %TEMP%\cc-out.txt

七、免责
    分数低只代表这次检测没撞到已知特征，不构成不封号的承诺。
    工具只读现状，不做任何规避风控的改动。
